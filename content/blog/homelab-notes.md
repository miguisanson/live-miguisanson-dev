## Practical uses

My homelab is a place to test deployment ideas before putting them on a public server. It is useful for learning how web apps behave when they need a database, a reverse proxy, logging, backups, and network access.

## What it teaches

- How to isolate services.
- How to debug port and DNS issues.
- How to make local apps reachable safely.
- How to recover from simple server failures.
