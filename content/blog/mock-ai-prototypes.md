## The reason

Before connecting a real model, it is better to understand the workflow. Mock outputs reveal what inputs matter, where users need control, and which generated results would actually be useful.

## Later integration points

- Add a server route for an LLM provider.
- Store user history with Prisma and PostgreSQL.
- Add authentication only when there is private user data to protect.
