## Overview

This project represents the infrastructure practice behind several local experiments: Linux hosting, reverse proxies, database-backed apps, tunnels, backups, and monitoring.

## Problem

Project demos need an environment where deployment issues can be tested without immediately depending on cloud hosting.

## Solution

A Linux server provides a repeatable place to host apps, test network paths, run databases, and practice operational recovery.

## Learnings

- Local servers make deployment problems concrete.
- Backups, logs, and service restarts matter even for small projects.
- Understanding the hosting layer improves frontend and backend decisions.
